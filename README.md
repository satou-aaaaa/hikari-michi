# ひかり道

鏡を置いて光を曲げ、部屋の宝石を全部通して出口へ届ける。いちばん少ない鏡の数を目指す、だれでも同じ1日3問のパズル。

- 遊ぶ: <https://satou-aaaaa.github.io/hikari-michi/>
- 光は左の明かりから右へ進みます。ますを押すと鏡を置け、押すたびに「／」→「＼」→なしと変わります。鏡に当たった光は直角に曲がり、鏡は表と裏の両方で光を曲げます。岩に当たると光は止まり、宝石は光が通りぬけます。はじめからある鏡（灰色）は動かせません。
- いちばん少ない鏡の数は、部屋を作るときに置き方を数えて出しています（問題の上に出ます）。その数で届けてヒントも使わなければ★3つ。
- 今日の3問（小部屋5×5・広間6×6・大広間6×7）はだれでも同じで1日1回。上級（6×8の部屋を2つ・ヒントなし）、練習、大きさごとの記録が残る部屋帳、実績があります。時間制限はありません。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（部屋の形や答えは入りません）。

## 開発

```bash
bash scripts/setup.sh   # 最初に一度
node qa/run.mjs         # 検査（CI と同じ）
node tools/make-icons.cjs && node tools/make-og.cjs   # アイコンと SNS 用の絵を作り直すとき
```
